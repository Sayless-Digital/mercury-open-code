# Mercury Coder

AI-powered code editor powered by OpenCode, with built-in voice transcription.

## Quick Start

```bash
# Install dependencies
npm install
cd backend-whisper && pip install -r requirements.txt && cd ..

# Run
npm run dev
```

Then configure your AI provider in Settings → Providers.

See [IMPLEMENTATION_GUIDE.md](./IMPLEMENTATION_GUIDE.md) for complete documentation.
